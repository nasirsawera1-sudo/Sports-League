# School Sports League

This is a Flask and SQLite website that I created for my Level 3 Digital Technologies project.

The purpose of my website is to help students easily find information about school sports. Users can view students, teams, team members, games, results, sports and playing locations.

## Features

- View students and teams
- View team members and roles
- View games, scores and results
- View sports and locations
- Search for records
- Use the navigation menu and Quick Access cards

## Tools I Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Visual Studio Code
- GitHub

## How to Run the Website

1. Download the project.
2. Open the folder in Visual Studio Code.
3. Install Flask:

   `pip install Flask`

4. Run the website:

   `python app.py`

5. Open the local address shown in the terminal.
